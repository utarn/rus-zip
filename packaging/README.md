# Package Manager Manifests & Distribution Guide

This directory contains manifest templates and instructions for distributing **RUS ZIP** across major package managers using the release artifacts produced by the GitLab CI/CD pipeline and hosted on [GitHub Releases (utarn/rus-zip)](https://github.com/utarn/rus-zip/releases).

---

## 1. Windows: WinGet (`packaging/winget/`)

WinGet installs the portable Windows x64 zip bundle (containing both `rus-zip` CLI and `RusZip` Desktop) and exposes both `rus-zip` and `RusZip` commands globally on the user's PATH.

* **Manifest Files**: `packaging/winget/` (3-file multi-file set, ManifestVersion 1.12.0)
  * `rus.zip.yaml` — **version** manifest
  * `rus.zip.installer.yaml` — **installer** manifest (portable nested zip)
  * `rus.zip.locale.en-US.yaml` — **defaultLocale** manifest
* **Package Identifier**: `rus.zip`
* **Aliases (Monikers)**: `rus.zip`, `rus-zip`, `ruszip`
* **Upstream Repository**: [microsoft/winget-pkgs](https://github.com/microsoft/winget-pkgs)
* **Submission Path**: `manifests/r/rus/zip/<version>/` (all three files)

> **Note**: Microsoft requires the **multi-file manifest format** — a singleton `ManifestType: singleton` is prohibited in the community repository. ManifestVersion must be `1.12.0` (1.10.0 minimum accepted). Do not use `AlternativeMonikers` — it is not part of the schema; only `Moniker` is supported.

### How to Submit to Microsoft `winget-pkgs`:

#### Method A: Using the official `wingetcreate` CLI tool (Recommended):
```powershell
# Run wingetcreate submit targeting the public GitHub release
wingetcreate submit https://github.com/utarn/rus-zip/releases/download/v1.0.0/rus-zip-win-x64.zip
```
`wingetcreate` will automatically download the public artifact, compute the SHA256 hash, generate the multi-file manifest set, validate it, and open a pull request against `microsoft/winget-pkgs`.

#### Method B: Manual PR to `microsoft/winget-pkgs`:
1. Fork and clone [microsoft/winget-pkgs](https://github.com/microsoft/winget-pkgs).
2. Create the directory `manifests/r/rus/zip/<version>/`.
3. Copy the three populated manifests generated by the CI build (attached to the GitHub Release) into `manifests/r/rus/zip/<version>/`.
4. Submit a PR. Once merged, Windows users can install via:
   ```powershell
   winget install rus.zip
   # OR
   winget install rus-zip
   # OR
   winget install ruszip
   ```

## 2. macOS: Homebrew Tap (`utarn/rus-zip`)

The `utarn/rus-zip` repository is structured to directly serve as a Homebrew Tap.

* **CLI Formula**: `Formula/rus-zip.rb` (at repository root)
* **Desktop App Cask**: `Casks/rus-zip.rb` (at repository root)

### User Installation:
```bash
# Add the tap
brew tap utarn/rus-zip

# Install CLI
brew install rus-zip

# Install Desktop UI application
brew install --cask rus-zip
```

Or install directly in a single command:
```bash
brew install utarn/rus-zip/rus-zip
brew install --cask utarn/rus-zip/rus-zip
```

## 3. Linux: Flatpak (`packaging/flatpak/`)

* **Manifest File**: `packaging/flatpak/com.ruszip.desktop.yaml`
* **Upstream Submission**: Submit to [Flathub](https://github.com/flathub/flathub).
* Fill in `<VERSION>` and `<SHA256_LINUX_TAR_GZ>` for `rus-zip-linux-x64.tar.gz`.

To test locally:
```bash
flatpak-builder --user --install --force-clean build-dir packaging/flatpak/com.ruszip.desktop.yaml
```

---

## 4. Linux: Snap (`packaging/snap/`)

* **Manifest File**: `packaging/snap/snapcraft.yaml`
* **Upstream Submission**: Register on [Snapcraft.io](https://snapcraft.io/) (`snapcraft register rus-zip`).
* Fill in `<VERSION>` and `<SHA256_LINUX_TAR_GZ>` for `rus-zip-linux-x64.tar.gz`.

To build locally:
```bash
snapcraft
```
